# Examples

## Fill A Selection

Stand at one corner:

```text
//pos1
```

Stand at the opposite corner:

```text
//pos2
```

Fill the selected area:

```text
//set stone
```

## Replace A Block Type

Replace dirt with grass blocks inside the selection:

```text
//replace dirt grass_block
```

## Build Walls

Select the two corners of the area and run:

```text
//walls oak_planks
```

## Select A Chunk

Select your current chunk:

```text
//chunk
```

Then change it:

```text
//set deepslate
```

## Expand A Selection

Expand 10 blocks in the direction you are facing:

```text
//expand 10
```

Expand 5 blocks up:

```text
//expand 5 up
```

Expand from bottom to top of the world:

```text
//expand vert
```

## Revert A Mistake

Undo the last edit:

```text
//undo
```

Redo it:

```text
//redo
```
